# 实验结果（Experiment Results）

这个文件夹集中存放本项目的实验证据，供评审直接查看，不需要跑代码。

## 看什么

1. **实验记录.md** —— 主文件。包含 30 组测试配对的逐条排名表、六组对照方案的指标、
   失败案例归类、权重对照表、交叉验证结果、复现命令。**只看这一份即可。**

2. **eval_result.json** —— 机器可读的完整结果。六组方案各自的 R@1 / R@5 / R@10 / MRR，
   以及每组的 30 条排名明细（某份岗位的正确答案排第几、当时第一名是谁）。

3. **eval_output.txt** —— 评测脚本一次完整运行的原始控制台输出，未经编辑。

4. **训练与评测报告.md** —— 面向报告的叙述版，行文更接近论文段落。

5. **weights.json** —— 被评测的模型权重（三组：人工先验 / 学出 44 组 / 学出 21 强），
   正文使用的是 learned_all44。

6. **eval.py** —— 评测脚本本身，可独立复现全部数字。

## 如何复现

    cd main\matcher
    python eval.py

约 8 秒，纯 CPU，不调用任何模型。脚本会重写 eval_result.json。

注：本文件夹是副本，原始文件位于 main\matcher\。修改请在原目录进行，改完再复制过来。
